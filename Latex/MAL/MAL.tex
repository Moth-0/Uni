\subsection{Entropy}
Another way to test decision tree is to base it on entropy. 
If we have $n$ point with $n_i$ as the numbers of points with label $i$. 
And $p_i = n/n_i$. Then entropy is: 
\begin{align*}
    H(S) = -\sum_{i=1}^{k} p_i\log_2 p_i. 
\end{align*}

Entropy is a measure of uncertainty in distrubtions, high entropy is high unsertainty. 
$H(S)$ describes the expected number of bits it takes to describe the label of a random element drawn from S. 
If all elements in $S$ er equal $H(S) = 0$. If there is an equal amount $H(S) = \log_2k$.

\section{Error}
In-Sample Error $(E_{in})$ is the error on the training data, and is what we try to minimize. 
The Out-Sample Error $(E_{out})$ is the error on the unknown data, this is what we wan't minimized. 
So we hope that $E_{in} \approx E_{out}$. 

\subsection{Loss Function Error}
For the speciel Loss function 0-1 Loss, we know the error is 
\begin{align*}
    E_{in}(h)=\frac{1}{n}\sum_{i=1}^{n}1_{h(x_i)\neq f(x_i)}.
\end{align*}
The Out-Sample error is just the probabilty that $h(x)\neq f(x)$. 

The Hoeffding inequality says that the probability of the two errors being father appart then some number $ε$ is
\begin{align*}
    P\br{\br[5]{E_{in}(h)-E_{out}(h)} > ε} \leq 2\e{-2ε^2n}, 
\end{align*} 
where $n$ is training examples. If we have multiple hypothesis $M$ we get: 
\begin{align*}
    P\br{\br[5]{E_{in}(h)-E_{out}(h)} > ε} \leq 2M\e{-2ε^2n}. 
\end{align*}
From this we can prove that minimizing $E_{in}(h)$ is a good strategy since for any other $h'$ in $H$, 
we get that $E_{out}(h) \leq 2ε+E_{out}(h')$, so any other $h'$ is at most $2ε$ better then $h$. 

We can also use Hoeffding inequality to find out what sampling size we should use. 
If we want the difference in error to be less then $0.1$ with $95\%$ confidence, and $M=1000$, we get: 
\begin{align*}
    2000\e{-2\cdot 0.1^2 n} < 0.05 \Rightarrow n > 50\ln(40.000) = 530, \\
    n > \frac{\ln(M/(1-c))}{2ε^2}. 
\end{align*}

If we are using an algorithm with infinite hypothesis, we can use a large number for $M$,
for hyperplanes representable using $d$ floats, that would be $M=2^{32d}$.

\section{Logitical Regression}
If we want to calculate a propability based on some data, we use logistical regression. 
To map a regression to a number between 0 and 1, we use the Sigmoid Function, 
\begin{align*}
    θ(z) = \frac{1}{1+\e{-z}}.
\end{align*}
So for our prediction function we use:
\begin{align*}
    θ(w^Tx) = \frac{1}{1+\e{-w^Tx}}. 
\end{align*}

So what we want is for $θ(w^Tx)$ to be equal to $P[y=1|x]$, 
the likelihood of seeing $y_i$ given $x_i$ is $θ(y_iw^Tx_i)$. 
Then the total likelihood of a data set (S) is 
\begin{align*}
    P[S|w,X] = \prod_{i=1}^{n}\frac{1}{1+\e{-y_iw^Tx_i}}, 
\end{align*}
which we can then maximise to get our prediction function. 
We do this by minimizing the average of the negativ log function: 
\begin{align*}
    E_{in}(w) &= -\frac{1}{n}\ln(P[S|w,X]) = \frac{1}{n}\sum_{i=1}^{n}\ln(1+\e{-y_iw^Tx_i}), \\
    \nabla E_{in}(w) &= -\frac{1}{n}\sum_{i=1}^{n}\frac{1}{1+\e{-y_iw^Tx_i}}\e{-y_iw^Tx_i}y_ix_i \\
    &= \frac{1}{n}\sum_{i=1}^{n}-y_ix_iθ(-y_iw^Tx_i). 
\end{align*}
But we can not set this function to 0 to minimize, so we use Gradient Decent, 
which is to "roll a ball down a hill", by guessing $w=w-η\nabla l(w)$, 
where $η$ is a step size (usually $η=0.1$) and $\nabla l(w)$ is the gradient of the function. 
But this can be slow, so we could use Stochastic Gradient Decent, be just taking a batch of datapoints, 
\begin{align*}
    g = \frac{1}{B}\sum_{i=1}^{B}-y'_ix'_iθ(-y'_iw^Tx'_i), \\
    w = w - ηg.
\end{align*}

\section{Growth Function}
The Growth Function states that there is a finite number of hypothesis sets, dependent on the number of points int the set
\begin{align*}
    m_H(n) = max_{x_1,...,x_n\in X}|\br[4]{(h(x_1),...,h(x_n)):h\in X}|.
\end{align*}
We can relate these hypothesis sets to $M$ in Hoeffdings inequality
\begin{align*}
    P\br{\br[5]{E_{in}(h)-E_{out}(h)} > ε} \leq 8m_H(2n)\e{-ε^2n/8}. 
\end{align*}

But it can be hard to find a function for $m_H(n)$, so instead we can bound the growth function with Shattering. 
If we have $k$ points in a 2D space, we need to be able to all $2^k$ dichotomies, 
meaning that we can create all subsets of points with hypothesis $H$. (See ML 15 video)
If all the dichotomies can be generated the points are shattered. 
If there is no data set of $k$ points that can be shattered then $k$ is a break point for $H$. 

This lead to the Vapnik-Chervonenkis dimension (VC dimension), which is $d$ such that $d=k-1$. 
From this we know that $m_H(n) \leq n^d+1$, then 
\begin{align*}
    P\br{\br[5]{E_{in}(h)-E_{out}(h)} > ε} \leq 8((2n)^d+1)\e{-ε^2n/8}. 
\end{align*}
Here we can see that given enough data we can always get that $E_{in}$ and $E_{out}$ are close, if the VC dimension is bounded ($d<\infty$). 
\bil{VC}

\chapter{Bias-Varience}
The goal of Bias Variance is to say something about the out of sample error like with VC dimensions, 
but this time we want to take our hypothesis into account. 
Here we find the bounding by 
\begin{align*}
    \mathbb{E}_D[E_{out}(h^D)] = \mathbb{E}_x[\mathbb{E}_D[(h^D(x)-\bar{h}(x))^2]]+\mathbb{E}_x[(\bar{h}(x)-f(x))^2],
\end{align*}
where $\bar{h}(x)$ is the average value of all the hypothsis we have trained
\begin{align*}
    \bar{h}(x) = \mathbb{E}_D[h^D](x)= \frac{1}{m}\sum_{i}h^{D_i}(x).
\end{align*}
We can note that $\mathbb{E}_x[\mathbb{E}_D[(h^D(x)-\bar{h}(x))^2]]$ is a measure of how far the hypothesis is of from the averge hypothesis, 
also called the variance. $\E_x[(\bar{h}(x)-f(x))^2]$ is then the bias, therby the name.

A Strong learner is a classifier that performs perfectly. 
We do this by training a lot of weak learners and combining them. 
If we have a weighted dataset with a distrubtion D over X, we can reweight the dataset, 
which is basically what bagging does. 

We run an algorithm (A) on a weigted training set (T) to get hypothesis set $h_t\in H$ and compute weights $α_t$. 
Then we return a voting classifier 
\begin{align*}
    f(x) = \text{sign}\br{\sum_{t=1}^{T}α_th_t(x)}.
\end{align*}

    &= \frac{\frac{1}{n}\text{exp}\br{-y_iF_t(x_i)}}{\prod_{j=1}^{t}Z_j}.

If T becomes big enough the in sample error will eventually become 0, meaning we have a stong learner. 
this happens if $T>\ln(n)/2γ^2$, where $γ = 1/2 - ε$, and $ε$ is the error of the weak learner.

\chapter{Support Vector Machines}
Support Vector Machines is an expansion of linear classification. 
We can use this when we have a large boundry between classes, to give a margin instead of just a line. 
We do this by maximising $γ$ in 
\begin{align*}
    &y_i(w^Tx_i+b)\geq γ, \quad i=1,...,n \\
    &||w|| = 1. 
\end{align*}
But this is not simple, so we change the function, with the requirement that it should be convex.
We need to minimize $||w||^2/2$ as a function of $w$ and $b$:
\begin{align*}
    y_i(w^Tx_i+b)\geq 1, \quad i=1,...,n
\end{align*}
\bil{svm1}

\section{Convex Optimization}
The general convex optimization problem is to minimize $f(x)$ subject to $g_i(x) \leq 0$
where $f$ and $g_i$ are convex functions. 
We do this with the generalized lagrangian:
\begin{align*}
    L(x, a) = f(x) + \sum_{i=1}^{n}a_ig_i(x).
\end{align*}
Given the constraints this means that we can solve: 
\begin{align*}
    \min_x θ_p(x) = \min_x\max_{a: a_i \geq 0} L(x,a). 
\end{align*}
this is the prime value $p^* = \min_x θ_p(x)$, we also introduce dual value: 
\begin{align*}
    θ_D(a) = \min_x L(x,a), \\
    d^* = \max_{a: a_i \geq 0}θ_d(a),
\end{align*}
and observe $d^* \leq p^*$. 
\bil{svm2}

To use this for SVM we set: 
\begin{align*}
    f(w, b) &= ||w||^2/2, \\
    g_i(w, b) &\leq 0, \\
    g_i(w, b) &\leq 1-y_i(w^Tx_i+b). 
\end{align*}
All these functions are convex, and we can therefore use the dual value. 
\begin{align*}
    &\max_{a: a_i \geq 0}\min_{w,b} f(w,b) + \sum_{i=1}^{n}a_ig_i(w,b), \\
    &\max_{a: a_i \geq 0}\min_{w,b} ||w||^2/2 - \sum_{i=1}^{n}a_i(y_i(w^Tx_i+b)-1). 
\end{align*}
From KKT conditions we can find that 
\begin{align*}
    &w = \sum_{i=1}^{n}a_iy_ix_i, \\
    &\sum_{i=1}^{n}a_iy_i = 0. 
\end{align*}
That gives the final problem: 
\begin{align*}
    &\max_{a: a_i \geq 0} \sum_{i=1}^{n}a_i-\frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n}a_ia_jy_iy_jx_i^Tx_j, \\
    &w = \sum_{i=1}^{n}a_iy_ix_i, \\
    &b = -\frac{1}{2}\br{\min_{i:y_1=1}w^Tx_i+\max_{i:y:i=-1}w^Tx_i}. 
\end{align*}

\section{Cluster Analysis}
Clustering is a way of splitting up data in clusters and is unsupervised learning. Data can be split up in more clusters creating a cluster hierarchi. 
A way of making these making these clusters is with k-means, where we make k clusters , defined from a cluster center. 
We then minimize the loss of this center. For a set of centers $C$ let $π(x)\in C$ be the cluster center. 
Then minimize 
\begin{align*}
    \text{cost}(S,C,π) = \sum_{X\in S}||x-π(x)||^2.
\end{align*}
It turns out that the point that reduces the cost is the mean of the points in the cluster. 
\begin{align*}
    π(x) = \frac{1}{|S_i|}\sum_{X\in S_i}x. 
\end{align*}

\section{Principal Component Analysis}
In PCA we project a feature vector onto a k-dimentional space, to reduce features to k. 
We project $x$ onto a subspace of k unit vectors $z_1, ..., z_k$. and get a new basis 
\begin{align*}
    \hat{x} = \begin{pmatrix}
        x^Tz_1 \\ \vdots \\ x^Tz_k
    \end{pmatrix}
\end{align*}

\bil{pca1}

To find $z_i$ we minimize the variance: 
\begin{align*}
    &\sum_{j=1}^{n}||x_j-\sum_{i=1}^{k}(x_j^Tz_i)z_||^2, \\
    &= -\sum_{j=1}^{n}\sum_{i=1}^{k}(x_j^Tz_i)^2,
\end{align*}
which is the same as maximizing 
\begin{align*}
    \sum_{j=1}^{n}\sum_{i=1}^{k}(XZ)_{i,j}^2 = \text{tr}(Z^TX^TXZ).
\end{align*}
