\chapter{Introduction }
For this project I had to look at Image Classification, by creating a simple neural network. 
This neural network is used to classify images of handwritten difgits from the MNIST database. 
These images are given in 28x28 grayscale images, where each pixel is a number between 0 and 255. 
I then use linear classification using a 784x10 matrix and a bias vector of size 10, to guess the number. 
A cost can be calculated from this guess, which is the mean square error of the guess and the actual number.
By minimizing this cost function using linear algebra, the weight matrix, and bias vector, can be updated using back propegation. 
The weights can then be visualized and the cost and accuracy can be plotted, to show how the neural network evolves.

\section{Reading Data}
For getting the raw data out of the MNIST files I had to first understand the format of the .gz files. 
For this I have used ChatGPT to help me understand  how to read the bytes in the file, to get the magic numbers. 
As can be see at \url{https://github.com/sunsided/mnist} the first 4 bytes of the files are the magic number, 
which is $2049$ for label files and $2051$ for images files. 
Then the files contains 4 bytes decriping the size of the file, additionally the image files contains 8 bytes for the size the images. 
After that comes the raw data which is a byte per label or pixel. 

To read the bytes I open the files with \code{gzip.open} (from \code{gzip} library) then read the files with \code{.read}. 
Then I plot the images with their correct label, to see that the data have been read correctly, since the first 5 numbers of 
\code{t10k-labels.idx1-ubyte.gz} are \code{[7, 2, 1, 0, 4]} as seen in figure \ref{fig:im1}.

\section{Linear Algebra}
Since numpy is not allowed in the project, I had to write linear algebra functions to use on list vectors and matrices.
These include vector addition, subtraction, and scalar multplication. 
I also wrote transpose and vector-matrix multiplication functions. 
The linear algebra used states that the guess for a number is found by calculating: 
\begin{align*}
    a = xA+b, 
\end{align*}
where $x$ is the image (in a 1x784 vector), $A$ is the weight matrix (784x10) and $b$ is the bias vector (1x10). 
With this the guess for the number is the index of the largest number in the vector $a$. 
From this guess the cost can be calculated as:
\begin{align*}
    \text{cost}(a, y) = \sum_i\frac{(a_i-y_i)^2}{10}. 
\end{align*}
So I have written functions to calculate these values and find the max index. 

For all the linear algebra functions i have used list comprhension as I find it easier write and understand. 
The \code{evaluate} function calculates this cost along with the predictions and the accuracy of the predictions. 
The accuracy the number of correct predictions divided by the total number of predictions.
I have then rewritten the \code{plot_images} function so it takes the optional argument \code{predictions}, which plots the images with their predicted labels.

I wrote assertation tests to check that the inputs to these function are the correct shape, which then makes sure the matrices stay the corrrect shape throuhout the code.
I also wrote assertation test to check that the output of the linear algebra functions are correctly calculated, and also added test to all othe function, 
to check that the inputs given are the expected type and size.

\section{Machine learning}
To make the neural network, Stochastic Gradient Descent is used. This means that the given training images are split up into random batches, 
for this the \code{create_batches} function is used, which uses the \code{random} library to shuffle the images. 
Then the network can be updated using formulas: 

\begin{align*}
    b_j &\text{ -= } σ \frac{1}{n} \sum_j 2\frac{a_j-y_j}{10}, \\
    A_{ij} &\text{ -= } σ \frac{1}{n} \sum_{i,j} 2x_i\frac{a_j-y_j}{10},
\end{align*}
where $σ$ is the step length which is set to $0.1$. Notice the -= because I did not, and i spend a lot of time not understanding why things didn't work. 
Here I used ChatGPT to help me understand the problem, and it told me i was updating the weights and biases instead of subtracting the values. 
In the code i first calculate the derivitive of the cost function using the linear algebra functions. 
I then use a nestet for loop to calculate every index of $A$. 

After that is the actual training of the network in the \code{learn} function. Here I first create a uniformly random network (using the \code{random} library), 
I then run it for an amount of epochs, where in each epoch the training set is split up into random batches of a set size. 
For every batch i run the \code{update} function, i then save the weights matrix and evaluation of the network, to be used in animations. 
For each epoch the time taken is recorded, and the network is evaluated on the full test set, and saved using \code{linear_save} if it is more accurate then the last. 

\chapter{Evaluation}
Along with these function I have written functions to plot and animate the evolution of the weights matrix, and the cost/accuracy of the network. 
To do this i have used the \code{matplotlib.pyplot} library and \code{matplotlib.animation.FuncAnimation} function. 
In figure \ref{fig:A} the trained weight matrix is shown. We can see a similar style to the MNIST weights, exept here we have more possitive weights. 
The accuracy is calculated after each batch, and after 4rd batch the accuracy maxes out at $86.67\%$, with a cost of $3.89$. 
We can also see the cost and accuracy as a function uf number of updates in figure \ref{fig:cost}.

The time taken to learn the neural network is around 3 minutes, at a batch size of 100, per epoch (on laptop). 
To make the grahps I had to append a copy of every weight matrix to a list, and evaluate the network on 300 random images after every batch. 
This added a lot of execution time to the code, so I added an option to not save this data. 
When running this on PC, where it would normally take 1 minute per epoch, it instead takes 2.5 minutes and 6.5 minutes on laptop. 
I also tried to play with the batch size, and found that a size of 2000 would run the full function in 1 minute per epoch, but the accuracy only reaches around $83\%$ at 5 epochs.

\chapter{Conclusion}
In this project, I implemented a simple neural network from scratch to classify handwritten digits from the MNIST dataset, 
without relying on external math libraries like \code{numpy}. To train the network I used stochastic gradient descent formulas for updating the weight matrix and bias vector. 

The network achieved an accuracy of up to 86.67\% after several epochs, demonstrating the effectiveness of a basic model for image classification. 
Additionally, visualizing the evolution of the weights, cost and accuracy provided valuable insights into the learning dynamics. 

Overall, this project enhanced my practical skills in programming and gave a good introduction to machine learning, 
it also highlighted the importance of careful implementation and debugging when building models from the ground up.
